# 🌟 Overview

Jarvis AI is an intelligent voice-controlled personal assistant built using **Python** and the **Google Gemini API**. It understands natural language voice commands, performs desktop automation, answers general questions, opens applications and websites, and interacts with users through speech.

The project is designed to demonstrate practical applications of **Artificial Intelligence**, **Natural Language Processing (NLP)**, **Speech Recognition**, and **Generative AI**.

# 🚀 Installation

## Clone Repository

```bash
git clone https://github.com/YOUR_USERNAME/Jarvis-AI.git
```

```bash
cd Jarvis-AI
```

---

## Install Dependencies

```bash
pip install -r requirements.txt
```

---

## Set Gemini API Key

Create an environment variable:

```
GEMINI_API_KEY=YOUR_API_KEY
```

---

## Run

```bash
python main.py
```

# 🎙 Voice Commands

| Command | Action |
|----------|--------|
| Open Google | Opens Google |
| Open YouTube | Opens YouTube |
| Open Wikipedia | Opens Wikipedia |
| Open VS Code | Opens VS Code |
| What is the time | Tells current time |
| Stop | Stops speaking |
| Sleep | Sleep mode |
| Wake up | Wake up Jarvis |
| Exit | Close Jarvis |
